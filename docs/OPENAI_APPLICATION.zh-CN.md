## 项目简介

IssueSieve 是一个面向开源维护者、强调人工复核的 GitHub Issue/PR 分诊与发布说明工具。它将不可信的贡献者输入转换为严格结构化建议，帮助维护者识别问题类型、优先级、缺失信息和下一步动作；疑似安全报告会转入私密人工流程，所有外部操作都保留明确的审核边界。
