# Security policy

## Reporting a vulnerability

Please do not open a public issue containing exploit details, credentials, private repository content, or personal data.

Until a private reporting address is published, use GitHub's private vulnerability reporting feature for this repository. Include affected versions, impact, and a minimal reproduction when safe. Maintainers will acknowledge a complete report as soon as practical, but no response or fix timeline is guaranteed.

## Scope and trust model

IssueSieve sends the configured issue, pull request, or release metadata to the selected OpenAI model. Do not use it on private material unless your organization has approved that data flow.

Repository text is untrusted input. Model output is advisory and may be wrong. Maintainers must review suggestions before changing labels, replying, closing work items, merging code, or publishing release notes.
